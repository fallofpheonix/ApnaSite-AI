# ADR-008: Anti-Corruption Layer for Migration

> **Status:** Accepted
> **Date:** 2026-07-13
> **Supersedes:** None
> **Superseded By:** None
> **Affects:** Implementation Spec, Migration Plan

## Context

The system has an existing `Site` model with a JSON blob (`StorefrontData`). A direct migration would break existing functionality and require a big-bang cutover.

## Decision

An Anti-Corruption Layer translates between the legacy Site model and the new Business aggregate. During migration:
- Existing Sites continue to work via the ACL
- New features use the Business aggregate directly
- Data is migrated incrementally
- Rollback is possible at every phase

## Consequences

**Positive:**
- Zero downtime migration
- Existing functionality preserved
- Incremental migration possible
- Rollback capability

**Negative:**
- Temporary code duplication
- ACL must be maintained during migration
- Two data models coexist temporarily
