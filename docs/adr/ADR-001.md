# ADR-001: Business is the Canonical Aggregate

> **Status:** Accepted
> **Date:** 2026-07-13
> **Supersedes:** None
> **Superseded By:** None
> **Affects:** Domain Model, Implementation Spec

## Context

The system needs a single source of truth for all business data. Previously, data was scattered across a `Site` model with a JSON blob (`StorefrontData`). This approach had no invariants, no event sourcing, and no clear ownership boundaries.

## Decision

The `Business` entity is the canonical aggregate root. All business data (profile, contact, address, location, hours, photos, social links, catalog, publishing) is owned by or associated with a Business.

## Consequences

**Positive:**
- Single entry point for all business operations
- Clear ownership boundaries
- Invariants enforced at the aggregate root
- Event sourcing becomes possible

**Negative:**
- Migration required from existing Site model
- Anti-Corruption Layer needed during transition
