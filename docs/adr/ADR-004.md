# ADR-004: Commands are the Only Write Interface

> **Status:** Accepted
> **Date:** 2026-07-13
> **Supersedes:** None
> **Superseded By:** None
> **Affects:** Domain Model, Implementation Spec

## Context

Without a single write interface, different parts of the system might modify state in different ways, making it impossible to maintain invariants or create an audit trail.

## Decision

All state mutations go through Commands. Commands are validated before execution and produce Domain Events. No code outside Command Handlers may modify aggregate state.

## Consequences

**Positive:**
- Invariants enforced at a single point
- Full audit trail of all changes
- Events automatically generated
- Easy to test (mock Commands, not entire domain)

**Negative:**
- More boilerplate
- Every change requires a Command definition
