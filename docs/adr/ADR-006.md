# ADR-006: Renderers are Pure Functions

> **Status:** Accepted
> **Date:** 2026-07-13
> **Supersedes:** None
> **Superseded By:** None
> **Affects:** Implementation Spec, Renderers

## Context

Renderers transform data into user-visible artifacts. If they have side effects (database access, API calls, file I/O), they become hard to test, debug, and reason about.

## Decision

Renderers are pure functions. Given a Read Model, they produce an Artifact. No side effects, no external dependencies, no state mutations.

## Consequences

**Positive:**
- Deterministic output
- Trivial to test
- No mocking required
- Easy to compose and chain

**Negative:**
- All data must be pre-computed in Read Models
- Cannot handle dynamic data (must be resolved before rendering)
