# ADR-002: Business Graph is the Intermediate Representation

> **Status:** Accepted
> **Date:** 2026-07-13
> **Supersedes:** None
> **Superseded By:** None
> **Affects:** Compiler Pipeline, Domain Model

## Context

The system needs a canonical data structure that all channels read from and all writes update. Without this, each channel would maintain its own data representation, leading to inconsistencies.

## Decision

The Business Graph is the Intermediate Representation (IR) of a business's canonical data. It is the single source of truth that:
- All channels read from
- All writes update
- All renderers consume (via Read Models)

## Consequences

**Positive:**
- Single source of truth across all channels
- Consistent data regardless of output channel
- Easy to add new channels (just add a new renderer)

**Negative:**
- Additional abstraction layer
- Must be kept in sync with all channels
