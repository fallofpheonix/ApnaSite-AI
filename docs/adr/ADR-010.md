# ADR-010: Publishing is Channel-Based

> **Status:** Accepted
> **Date:** 2026-07-13
> **Supersedes:** None
> **Superseded By:** None
> **Affects:** Publishing Context, Domain Model

## Context

A business needs to publish its information across multiple channels (Website, WhatsApp, Google Business, Instagram). Each channel has different requirements and formats.

## Decision

Publishing is channel-based. Each channel has its own configuration, Read Model, and Renderer. A Business can publish to multiple channels independently. Each channel has its own lifecycle (draft → published → unpublished).

## Consequences

**Positive:**
- Channels can be published/unpublished independently
- Each channel can have its own configuration
- Easy to add new channels
- Channel-specific optimizations possible

**Negative:**
- More complex than single-channel publishing
- Each channel requires its own Renderer
- Read Models must be channel-specific
