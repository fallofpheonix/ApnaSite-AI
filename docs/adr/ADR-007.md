# ADR-007: Events are Append-Only

> **Status:** Accepted
> **Date:** 2026-07-13
> **Supersedes:** None
> **Superseded By:** None
> **Affects:** Domain Model, History Context

## Context

The system needs an audit trail of all changes. If events can be modified or deleted, the audit trail becomes unreliable and rollback becomes impossible.

## Decision

Domain Events are append-only. Once recorded, they cannot be modified or deleted. History is reconstructed by replaying events from the beginning or from a Snapshot.

## Consequences

**Positive:**
- Complete audit trail
- Rollback capability via Snapshot + replay
- Event sourcing becomes possible
- History is immutable and trustworthy

**Negative:**
- Storage grows over time (mitigated by Snapshots)
- Cannot "undo" by deleting events (must add compensating events)
