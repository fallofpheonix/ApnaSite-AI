# ADR-005: Read Models Power Renderers

> **Status:** Accepted
> **Date:** 2026-07-13
> **Supersedes:** None
> **Superseded By:** None
> **Affects:** Domain Model, Implementation Spec

## Context

Renderers need data to produce artifacts. If they read directly from aggregates, they would have side effects, be hard to test, and create performance bottlenecks.

## Decision

Renderers consume only Read Models. Read Models are pre-computed views derived from Domain Events. Renderers never access aggregates or the Business Graph directly.

## Consequences

**Positive:**
- Renders are deterministic (same Read Model = same output)
- No side effects during rendering
- Easy to test (mock Read Models)
- Performance (Read Models are pre-computed)

**Negative:**
- Read Models must be kept in sync with aggregates
- Additional projection layer
