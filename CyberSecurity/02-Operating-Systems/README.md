# 02: Operating Systems

## Purpose

Understand how operating systems manage hardware resources, processes, memory, and file systems. This knowledge is essential for system security, hardening, and identifying OS-level vulnerabilities.

## Learning Goals

- Explain operating system architecture and components
- Describe process and memory management concepts
- Understand file system structures and operations
- Recognize OS security mechanisms and features

## Topics

- OS Architecture
- Process Management
- Memory Management
- File Systems
- System Security Features

## Prerequisites

- 01: Fundamental IT Skills
- Basic understanding of computer hardware

## Leads To

This knowledge is required for:
- 03: Linux (Linux-specific OS internals)
- 04: Windows (Windows-specific OS internals)
- 10: System Security (OS hardening and configuration)
