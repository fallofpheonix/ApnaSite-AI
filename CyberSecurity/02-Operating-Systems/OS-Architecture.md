# OS Architecture

## What is it?

OS Architecture refers to the foundational design of an operating system, including how it manages hardware resources and provides services to applications. It encompasses kernel modes (user mode vs kernel mode), system calls that bridge applications to kernel services, and layered architecture that separates concerns. The architecture determines how privilege levels are enforced and how components interact.

## Why Learn It?

Understanding OS architecture is essential for cybersecurity because security vulnerabilities often arise from improper privilege separation, flawed system call handling, or misconfigured kernel modes. Knowing how the kernel operates helps identify attack surfaces, understand privilege escalation exploits, and design secure systems. It forms the foundation for studying all other OS security topics.
