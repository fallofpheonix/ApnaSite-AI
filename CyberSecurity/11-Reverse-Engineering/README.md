# 11: Reverse Engineering

## Purpose

Analyze compiled software to understand its functionality, identify vulnerabilities, and understand malware behavior. Reverse engineering is essential for vulnerability research and malware analysis.

## Learning Goals

- Read and understand assembly language
- Use debugging tools to analyze program behavior
- Perform static and dynamic code analysis
- Identify anti-analysis techniques
- Extract indicators from compiled binaries

## Topics

- Assembly Language
- Debugging
- Static Analysis
- Dynamic Analysis
- Anti-Reverse Engineering

## Prerequisites

- 04: Windows (PE files, Windows internals)
- 06: Programming (code comprehension)
- 03: Linux (ELF files, Linux tools)

## Leads To

This knowledge is required for:
- 12: Malware Analysis (analyzing malicious code)
- 14: Penetration Testing (exploit analysis)
