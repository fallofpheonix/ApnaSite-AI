# 03: Linux

## Purpose

Master Linux operating system fundamentals, command-line proficiency, and system administration. Linux is the primary platform for security tools, servers, and penetration testing environments.

## Learning Goals

- Navigate Linux systems using the command line
- Manage files, permissions, and users effectively
- Write shell scripts for automation
- Perform basic system administration tasks
- Understand Linux security model

## Topics

- Linux Fundamentals
- Command Line Interface
- File System Structure
- Permissions and Users
- Shell Scripting
- System Administration

## Prerequisites

- 02: Operating Systems
- Basic command line exposure

## Leads To

This knowledge is required for:
- 05: Networking (network configuration in Linux)
- 06: Programming (scripting and automation)
- 14: Penetration Testing (Kali Linux and security tools)
