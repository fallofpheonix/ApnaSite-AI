# 06: Programming

## Purpose

Develop programming skills essential for security automation, tool development, vulnerability research, and understanding attack vectors. Programming is a force multiplier for cybersecurity professionals.

## Learning Goals

- Write Python scripts for security tasks
- Automate repetitive security operations
- Understand web technologies (HTML, JavaScript, databases)
- Interact with APIs for data retrieval and automation
- Read and understand code for vulnerability analysis

## Topics

- Python for Security
- Scripting and Automation
- Web Technologies
- Database Basics
- API Interaction

## Prerequisites

- 05: Networking (protocols and web basics)
- Logical thinking and problem-solving

## Leads To

This knowledge is required for:
- 09: Web Security (understanding web code)
- 11: Reverse Engineering (code analysis)
- 14: Penetration Testing (exploit development)
