# 08: Cryptography

## Purpose

Master the mathematical foundations and practical applications of cryptographic systems. Understanding cryptography is essential for secure communications, data protection, and analyzing cryptographic weaknesses.

## Learning Goals

- Differentiate between symmetric and asymmetric encryption
- Understand hashing algorithms and their uses
- Implement PKI and certificate management
- Identify cryptographic attacks and weaknesses
- Apply cryptography to secure communications

## Topics

- Symmetric Encryption
- Asymmetric Encryption
- Hashing Algorithms
- PKI and Certificates
- Cryptographic Attacks

## Prerequisites

- 07: Security Fundamentals
- Basic mathematics (modular arithmetic)

## Leads To

This knowledge is required for:
- 09: Web Security (TLS/SSL, authentication)
- 10: System Security (encryption at rest)
- 11: Reverse Engineering (crypto analysis)
