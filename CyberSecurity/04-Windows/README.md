# 04: Windows

## Purpose

Understand Windows operating system internals, administration, and security features. Essential for enterprise security, Active Directory environments, and Windows-specific attack vectors.

## Learning Goals

- Explain Windows architecture and components
- Navigate the Windows Registry and its security implications
- Manage Active Directory and Group Policy
- Utilize PowerShell for administration and security
- Apply Windows security tools and configurations

## Topics

- Windows Architecture
- Windows Registry
- Active Directory
- PowerShell
- Windows Security Tools

## Prerequisites

- 02: Operating Systems
- Basic Windows user experience

## Leads To

This knowledge is required for:
- 10: System Security (Windows hardening)
- 14: Penetration Testing (Windows attack techniques)
