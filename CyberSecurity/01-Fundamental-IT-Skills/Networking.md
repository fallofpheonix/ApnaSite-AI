# Networking

## What is it?

Networking covers the fundamental concepts of how computers communicate over local and wide area networks. This includes IP addressing, ports, protocols, and the OSI model. These basics form the foundation for deeper network security study.

## Why Learn It?

Nearly all cyberattacks traverse a network. Understanding networking fundamentals is required to detect malicious traffic, implement firewalls, and secure communications. Without this knowledge, advanced network security topics are inaccessible.

## You Will Learn

- LAN vs. WAN architecture and differences
- IP addressing (IPv4, IPv6) and subnetting basics
- Ports, protocols, and the OSI model
- Common network services (DNS, DHCP, HTTP)
- Network device functions (routers, switches, firewalls)
