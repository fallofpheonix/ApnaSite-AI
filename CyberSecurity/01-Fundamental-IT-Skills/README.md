# 01: Fundamental IT Skills

## Purpose

Establish core knowledge of computer hardware, networking basics, troubleshooting methodologies, and productivity tools. This section provides the essential foundation required before advancing to operating systems and security topics.

## Learning Goals

- Understand computer hardware components and their functions
- Identify different network connection types and their characteristics
- Apply systematic troubleshooting approaches to IT problems
- Use office productivity software effectively
- Grasp basic networking concepts and terminology

## Topics

- Computer Hardware
- Connection Types
- Troubleshooting Methodologies
- Office Suites
- Networking Basics

## Prerequisites

- Basic computer literacy
- Ability to use a web browser

## Leads To

This knowledge is required for:
- 02: Operating Systems (understanding how hardware and OS interact)
- 05: Networking (deeper protocol and architecture study)
- 10: System Security (physical and hardware security concepts)
