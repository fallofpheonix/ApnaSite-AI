# 05: Networking

## Purpose

Deep dive into network protocols, architectures, and security mechanisms. Understanding networking is critical for analyzing traffic, detecting attacks, and implementing network defenses.

## Learning Goals

- Master TCP/IP protocol suite in depth
- Understand DNS, DHCP, and other core services
- Configure and analyze firewalls and IDS/IPS
- Capture and analyze network traffic
- Identify network-based attacks

## Topics

- Network Protocols
- TCP/IP Deep Dive
- DNS and DHCP
- Firewalls and IDS/IPS
- Network Analysis

## Prerequisites

- 01: Fundamental IT Skills (networking basics)
- 02: Operating Systems

## Leads To

This knowledge is required for:
- 09: Web Security (HTTP/HTTPS protocols)
- 13: Cloud Security (cloud networking)
- 14: Penetration Testing (network attacks)
