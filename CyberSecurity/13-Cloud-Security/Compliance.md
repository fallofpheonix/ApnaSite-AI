# Compliance

## What is it?

Cloud compliance ensures that cloud deployments meet regulatory requirements, industry standards, and organizational policies. It involves audits, certifications, and continuous monitoring. Major frameworks include GDPR, HIPAA, SOC 2, ISO 27001, and PCI DSS, each with specific cloud requirements.

## Why Learn It?

Non-compliance results in heavy fines, legal action, and reputational damage. Cloud providers offer compliance programs, but shared responsibility means customers must still implement controls. Understanding compliance frameworks is essential for any cloud security role.

## You Will Learn

- Key regulatory frameworks and their cloud-specific requirements
- Cloud provider compliance programs and certifications
- Audit preparation and evidence collection in the cloud
- Continuous compliance monitoring and automated remediation
- Risk assessment and policy enforcement for cloud workloads
