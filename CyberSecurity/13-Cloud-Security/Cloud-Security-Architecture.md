# Cloud Security Architecture

## What is it?

Cloud security architecture defines how to design and deploy secure infrastructure in the cloud. It covers VPC design, security groups, network ACLs, and infrastructure as code (IaC) security. A strong architecture minimizes attack surfaces and enforces defense-in-depth from the network layer to the application layer.

## Why Learn It?

Cloud environments are dynamic and API-driven. Without a well-defined security architecture, organizations expose themselves to misconfigurations, lateral movement, and data exfiltration. Cloud-native security patterns like zero-trust networking and immutable infrastructure are essential for modern defenses.

## You Will Learn

- VPC design principles including segmentation and subnet isolation
- Security groups and network ACLs for traffic control
- Infrastructure as Code security and drift detection
- Cloud-native zero-trust and microsegmentation patterns
- Logging, monitoring, and threat detection in cloud environments
